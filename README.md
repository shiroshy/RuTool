# RuTool Installer

Открытый клиент установки перевода Blue Archive.
Собственный код распространяется под Apache-2.0; сторонние компоненты
и изображения сохраняют свои условия. См. [лицензию](client-v2/LICENSE)
и [уведомления](client-v2/NOTICE).

## Linux

Ветка `linux` содержит нативный Qt/QML-клиент и сборку AppImage для x86_64.
Минимальная версия glibc — 2.35. Публичный Linux-выпуск готовится;
канал обновлений ещё не настроен.

- [Запуск и сборка](client-v2/BUILDING-LINUX.md)
- [Документация](client-v2/docs/README.md)
- [Подготовка выпуска](client-v2/docs/LINUX-DEVELOPMENT.md)
