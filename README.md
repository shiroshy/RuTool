# RuTool Installer

Открытый код инсталлера находится в [client-v2](client-v2/).
Собственный код распространяется под Apache-2.0; сторонние компоненты и
изображения сохраняют свои условия. См. `client-v2/LICENSE` и `client-v2/NOTICE`

## Linux

Ветка `linux-port` содержит нативный клиент для Linux x86_64 и скрипты сборки
AppImage. Установка перевода, работа игры и восстановление оригиналов проверены
на одном Linux-компьютере; другие дистрибутивы ещё требуют проверки.

- [Запуск и сборка](client-v2/BUILDING-LINUX.md)
- [Устройство порта](client-v2/docs/LINUX-IMPLEMENTATION.md)
- [Результаты проверок и ограничения](client-v2/docs/LINUX-VALIDATION.md)
