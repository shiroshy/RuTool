# RuTool Installer

Клиент установки перевода Blue Archive. Linux-версия — **2.1.1L**.
Это предварительный выпуск для тестирования.

## Linux

Нужны Linux x86_64, glibc 2.35 или новее, Wayland либо X11
и права записи в папку игры. Qt включён в AppImage.
Для загрузки и проверки переводов нужен интернет.

Скачай AppImage из [Releases](https://github.com/shiroshy/RuTool/releases/tag/v2.1.1L)
и запусти:

```sh
chmod +x RuTool-2.1.1L-x86_64.AppImage
./RuTool-2.1.1L-x86_64.AppImage
```

Если FUSE недоступен:

```sh
./RuTool-2.1.1L-x86_64.AppImage --appimage-extract-and-run
```

Клиент ищет игру в Steam и Proton. Папку можно выбрать вручную в настройках.
Перед установкой и восстановлением закрой игру.

## Обновления и данные

Кнопка «Проверить обновления» получает подписанный Linux-канал.
При появлении новой версии клиент скачает AppImage, проверит его,
сохранит предыдущую версию и предложит перезапуск.
После сбоя нового интерфейса автоматического возврата к старой версии нет;
сохранённый предыдущий AppImage можно запустить вручную.

Настройки, загрузки, резервные копии и локальный ключ хранятся вне AppImage,
в каталоге данных RuToolInstaller по правилам XDG. Замена приложения их
не удаляет. Не удаляй локальный ключ и копии, пока нужно восстановление.
Выбранный вручную файл перевода после установки сохраняется.

## Что проверить

- Загрузку перевода, установку, запуск игры и восстановление оригиналов.
- Запуск AppImage с FUSE и без него, Wayland/X11, масштабирование и Steam Deck.
- Обнаружение игры и её процесса через Proton.

Steam Deck, реальные Premium-сценарии, NTFS, exFAT и сетевые диски пока
не подтверждены. Извлечённое приложение проверено на glibc 2.35;
это не заменяет проверку обычного запуска AppImage на твоей системе.

Для сообщения об ошибке используй форму в приложении. Укажи систему,
тип графической сессии, способ запуска и шаги воспроизведения.
Проверь журнал и вложения на личные данные перед отправкой.
